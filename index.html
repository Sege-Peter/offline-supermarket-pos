⚡ Atomic Checkout Transaction (MySQL InnoDB)

Using row-level locking (SELECT ... FOR UPDATE) inside an atomic transaction ensures multiple lanes cannot oversell the same inventory concurrently:

-- Atomic Transaction Guarantee START TRANSACTION; -- 1. Insert Sales Header INSERT INTO sales (receipt_number, cashier_name, total, payment_method) VALUES ('REC-20260922-01', 'Lane 01', 15.01, 'CASH'); -- 2. Lock and Check Stock Quantity SELECT stock_quantity FROM products WHERE id = 1 FOR UPDATE; -- 3. Decrement Inventory UPDATE products SET stock_quantity = stock_quantity - 2 WHERE id = 1; -- 4. Insert Line Items INSERT INTO sale_items (sale_id, product_id, quantity, unit_price, total_price) VALUES (LAST_INSERT_ID(), 1, 2, 1.50, 3.00); COMMIT;
